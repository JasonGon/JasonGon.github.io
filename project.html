The Financial Dilemma

As part of the graduation with distinction in STEM program, I worked on an educational visual novel titled, "The Financial Dilemma". Programmed in the visual novel engine Renpy, the game follows a teenager trying to be responsible with money.

I wanted to create a 'realistic' scenario, so in addition to managing their bank balance, the player must also manage a 'social bar', which represents your relationship with your friends. For example, while choosing not to go out for fun will save you money, it will also decrease how social you are.

Comp350 File System

For the last project in my Operating Systems class, I was put into a group with three other students and tasked with building a simplified, command-line file system.

This project was programmed in a Linux virtual machine in the terminal, and it allows users to clear, create, delete, edit, and list files on a virtual drive.
